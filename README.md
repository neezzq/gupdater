# GUpdater

Программа для компьютерного клуба, которая сама обновляет игры во всех
лаунчерах: Steam, Epic Games, VK Play, Battle.net, Riot, EA app, Lesta Game
Center и iCCup.

**Скачать:** https://github.com/neezzq/gupdater/releases/latest (файл `GUpdater.exe`
в блоке **Assets**). Если Windows покажет «Windows защитила ваш компьютер»,
нажмите **Подробнее → Выполнить в любом случае**: у программы пока нет
цифровой подписи.

## Как это работает

Лаунчеры не дают сторонним программам скачивать обновления за них, поэтому
GUpdater работает как автопилот:

1. Ждёт, пока за компьютером никого нет (при запуске по расписанию).
2. По очереди открывает лаунчеры. Каждый сам находит и качает обновления, а
   GUpdater следит за этим по активности диска и сети. Steam дополнительно сам
   сообщает, какие игры ещё ждут обновления.
3. Когда лаунчер несколько минут ничего не качает, GUpdater закрывает его и
   переходит к следующему.
4. Пишет отчёт: что обновилось, а где нужна помощь администратора.

## Этапы

| Этап | Что делает | Готово |
|---|---|---|
| 1. Разведка | Находит лаунчеры и игры на ПК, сохраняет отчёт | ✅ |
| 2. Автопилот | Очередь лаунчеров, расписание, отчёт, обновление программы по кнопке | ✅ |
| 3. Запомнить вход | Вход клуба подставляется только на время обновления (игроки сидят под своими аккаунтами) | ✅ |
| 4. Все ПК клуба | Пульт администратора, обновление свободных ПК | ✅ |

## Как пользоваться

1. Положите `GUpdater.exe` на диск с играми, например `D:\GUpdater\`. Рядом с
   ним программа хранит настройки (`GUpdater.settings.json`) и отчёты (папка
   `GUpdater-отчёты`). Диск C: в клубах часто «заморожен» и после перезагрузки
   всё на нём теряется.
2. Войдите в каждый лаунчер и включите в его настройках автообновление игр.
3. Вкладка **«Автопилот»**: отметьте галочками, какие лаунчеры обновлять,
   кнопками «Выше»/«Ниже» задайте порядок и нажмите **«Запустить сейчас»**.
4. Чтобы обновлять каждый день: включите **«Запускать каждый день в …»** и
   нажмите **«Применить расписание»**. В Планировщике Windows появится задание
   «GUpdater Autopilot». Оно ждёт, пока за компьютером никого нет, обновляет
   игры и останавливается, если за компьютер сели.

### Вход клуба (вкладка «Входы»)

Игроки сидят в лаунчерах под своими аккаунтами, поэтому вход клуба не может
просто оставаться в лаунчере. GUpdater хранит его отдельно и подставляет только
на время обновления:

1. **«Запомнить вход…»**. GUpdater закрывает лаунчер и запоминает, как он
   выглядит сейчас. Вы входите под аккаунтом клуба с «Запомнить меня» и нажимаете
   «Готово». GUpdater сохраняет то, что изменилось при входе, и возвращает лаунчер
   в прежнее состояние. Из аккаунта никто не выходит, так что сохранённый вход
   остаётся рабочим.
2. **При обновлении** GUpdater откладывает текущее состояние лаунчера, подставляет
   вход клуба, обновляет игры, закрывает лаунчер и возвращает всё как было. Если
   лаунчер за это время обновил свой вход, новый вход сохраняется.
3. Если GUpdater прервётся посреди обновления, при следующем запуске он сначала
   уберёт вход клуба из лаунчеров.

Где лежат данные входа, заранее известно для Steam, Epic, Riot и Battle.net. Для
VK Play, Lesta, EA и iCCup мастер сам находит изменившиеся файлы. Всё хранится в
папке `GUpdater-входы` рядом с программой, зашифрованное ключом этого компьютера
(он не меняется при перезагрузке): на другом ПК эти файлы бесполезны.

**Если после перезагрузки все выходят из аккаунтов** (откат диска через Shadow
Defender, Deep Freeze и т. п.), игры всё равно обновятся. Достаточно трёх вещей:

1. `GUpdater.exe` лежит на незащищённом диске с играми, тогда настройки и входы
   переживают перезагрузку.
2. Мастер «Запомнить вход» пройден при выключенной защите (или изменения
   сохранены в программе заморозки).
3. Расписание включено при выключенной защите. Если задание всё же пропадёт,
   GUpdater восстановит его при следующем запуске.

GUpdater сам замечает такие программы и показывает об этом предупреждение.

Вкладка **«Игры на этом ПК»** показывает найденные лаунчеры и игры. Там же
сохраняется отчёт разведки, в котором нет имён аккаунтов, почты и данных входа.

### Обновление самой программы

Справа вверху видна версия. Если на GitHub вышла новая, кнопка станет
**«Обновить до …»**: программа скачает новую версию, проверит контрольную
сумму, заменит себя и перезапустится.

### Запуск из командной строки

```
GUpdater.exe --autopilot          обновить игры и закрыться (так запускает планировщик)
GUpdater.exe --autopilot --now    то же, но не ждать, пока компьютер освободится
GUpdater.exe --report отчёт.txt   без окна записать отчёт разведки
GUpdater.exe --demo               окно с ненастоящими данными
```

## Для разработки

```
pip install -e ".[dev]"
python -m pytest
python -m gupdater --demo
```

Код:

- `gupdater/launchers/`: поиск лаунчеров и игр, а также как запускать, отслеживать
  и закрывать каждый лаунчер.
- `gupdater/autopilot/`: движок автопилота (`engine.py`), работа с процессами
  (`system.py`), Планировщик Windows (`scheduler.py`), отчёт (`report.py`).
- `gupdater/logins.py` и `gupdater/autopilot/login_wizard.py`: этап 3, вход клуба.
- `gupdater/selfupdate.py`: обновление программы из GitHub Releases.
- `gupdater/ui/theme.py`: оформление (графит, «стекло»). Логотип рисует
  `scripts/make_logo.py`.
- `gupdater/demo.py`: ненастоящий компьютер для тестов и `--demo`. Лаунчеры в
  нём «качают» в ускоренном времени.
- `gupdater/ui/`: окно программы.

`GUpdater.exe` собирается автоматически на GitHub (`.github/workflows/build.yml`)
при каждом изменении кода. Там же готовый exe проверяется на настоящей Windows:
окно, отчёт, прогон автопилота, замена самого себя. Если всё прошло, файл
кладётся в релиз `v<версия>` (версия берётся из `gupdater/__init__.py`) и
заменяет предыдущую сборку этой версии. Чтобы появился новый релиз, поднимите
версию и обновите `RELEASE_NOTES.md`.
