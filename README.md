# GUpdater

Программа для компьютерного клуба, которая будет сама обновлять игры во всех
лаунчерах: Steam, Epic Games, VK Play, Battle.net, Riot, EA app, Lesta Game
Center и iCCup.

## Как это будет работать

Лаунчеры не дают сторонним программам скачивать обновления за них, поэтому
GUpdater работает как автопилот:

1. Проверяет, что за ПК никто не играет.
2. Подставляет сохранённый вход клуба в лаунчер (игроки на ПК сидят под своими
   аккаунтами, поэтому вход клуба хранится отдельно и убирается после обновления).
3. По очереди открывает лаунчеры, ждёт, пока каждый скачает обновления, и
   закрывает его.
4. Пишет отчёт: что обновилось, а где нужна помощь администратора.

## Этапы

| Этап | Что делает | Готово |
|---|---|---|
| 1. Разведка | Находит лаунчеры и игры на ПК, сохраняет отчёт | ✅ |
| 2. Автопилот | Очередь лаунчеров, ожидание окончания загрузки, отчёт | |
| 3. Запомнить вход | Вход клуба подставляется только на время обновления | |
| 4. Все ПК клуба | Пульт администратора, обновление свободных ПК (SmartShell) | |

## Этап 1: разведка

Программа ничего не меняет и не обновляет, только смотрит.

1. Скачайте `GUpdater.exe` из раздела **Releases**:
   https://github.com/neezzq/gupdater/releases/latest (блок **Assets**).
2. Запустите его на одном из ПК клуба под администратором. Если Windows
   покажет синее окно «Windows защитила ваш компьютер», нажмите
   **Подробнее → Выполнить в любом случае**: у программы пока нет цифровой подписи.
3. Нажмите **Сохранить отчёт…** и пришлите файл в чат.

В отчёт не попадают имена аккаунтов, почта и данные входа. Папка пользователя
Windows заменяется на `%USERPROFILE%`.

Запуск без окна (например, через SmartShell на всех ПК сразу):

```
GUpdater.exe --report C:\gupdater-report.txt
```

`GUpdater.exe --demo` показывает окно с ненастоящими данными.

## Для разработки

```
pip install -e ".[dev]"
python -m pytest
python -m gupdater --demo
```

Код:

- `gupdater/launchers/`: поиск лаунчеров и игр, по одному модулю на лаунчер.
- `gupdater/core/`: реестр Windows, разбор файлов Steam, общие модели.
- `gupdater/report.py`: отчёт разведки.
- `gupdater/ui/`: окно программы.

`GUpdater.exe` собирается автоматически на GitHub (`.github/workflows/build.yml`)
при каждом изменении кода. Если тесты и проверка exe прошли, файл кладётся в
релиз `v<версия>` (версия берётся из `gupdater/__init__.py`) и заменяет
предыдущую сборку этой версии. Чтобы появился новый релиз, поднимите версию и
обновите `RELEASE_NOTES.md`.
